Bab 1 • Dasar

Mengenal Microsoft Excel

1.1 Apa itu Excel?

Microsoft Excel adalah aplikasi spreadsheet untuk menyimpan, menghitung, mengolah, menganalisis, dan menyajikan data. Contoh penggunaan: daftar nilai siswa, inventaris, anggaran, penjualan, jadwal, dan laporan keuangan sederhana.

1.2 Istilah penting

1.3 Bagian layar

  • Ribbon: kumpulan menu seperti Home, Insert, Data, dan View.
  • Name Box: menampilkan alamat sel aktif.
  • Formula Bar: melihat atau mengedit isi sel dan rumus.
  • Worksheet: area untuk mengolah data.
  • Sheet tabs: berpindah atau menambah lembar.

1.4 Membuat dan menyimpan file

  1. Buka Excel lalu pilih Blank workbook.
  2. Klik A1 dan ketik data.
  3. Pilih File → Save As, tentukan lokasi dan nama file.
  4. Simpan dengan format .xlsx.
  5. Tekan Ctrl+S secara berkala.

Bab 2 • Dasar

Memasukkan dan Mengelola Data

2.1 Memasukkan data

Klik sel, ketik teks/angka/tanggal, lalu tekan Enter. Tekan F2 atau klik Formula Bar untuk mengedit data yang sudah ada. Tab biasanya berpindah ke sel sebelah kanan.

2.2 Jenis data

Angka125000Dapat dihitung.
Tanggal21/10/2026Format mengikuti pengaturan regional.
Persentase15%Nilai dasar 0,15.
Rumus=B2*C2Hasil dihitung Excel.

2.3 Mengisi data lebih cepat

Gunakan fill handle (kotak kecil di sudut sel) untuk menyalin rumus atau meneruskan pola. Salin rumus dengan Ctrl+C lalu tempel Ctrl+V; referensi relatif biasanya menyesuaikan otomatis.

2.4 Mengatur baris dan kolom

  1. Seret batas huruf kolom untuk mengubah lebar.
  2. Klik dua kali batas kolom untuk AutoFit.
  3. Home → Format untuk mengatur Column Width atau Row Height.
  4. Wrap Text membuat teks panjang tampil beberapa baris.

2.5 Format angka

Home menyediakan Number, Currency/Accounting, Date, Percentage, dan Text. Format mengubah tampilan, bukan selalu nilai dasar. Misalnya 0,15 yang diformat sebagai persen tampil sebagai 15%.

Bab 3 • Dasar

Membuat Tabel Rapi dan Profesional

3.1 Format sel

Tab Home menyediakan Bold, Italic, warna teks, warna isi, border, perataan, dan format angka. Gunakan satu gaya judul yang konsisten dan jangan terlalu banyak warna.

3.2 Format as Table

  1. Blok data beserta judul kolom.
  2. Pilih Home → Format as Table.
  3. Pilih gaya dan pastikan My table has headers dicentang bila baris pertama adalah judul.
  4. Gunakan filter pada header untuk menyaring dan mengurutkan.

3.3 Fitur yang berguna

  • Wrap Text: membungkus teks panjang.
  • Merge & Center: menggabungkan sel untuk judul; hindari di dalam tabel data.
  • Conditional Formatting: menyorot data berdasarkan aturan.
  • Freeze Panes: mempertahankan header saat menggulir.
  • Borders: membantu pembaca mengikuti baris dan kolom.

3.4 Conditional Formatting: nilai di bawah 75

  1. Pilih rentang nilai, misalnya C2:C30.
  2. Home → Conditional Formatting.
  3. Pilih Highlight Cells Rules → Less Than.
  4. Masukkan 75 dan pilih gaya warna.
Tips: jangan gunakan Merge & Center pada baris data yang akan diurutkan atau dijadikan sumber PivotTable. Header harus unik dan setiap kolom hanya memiliki satu jenis informasi.

Semua rumus dimulai dengan =. Operator: + tambah, - kurang, * kali, / bagi, ^ pangkat. Gunakan tanda kurung untuk mengatur urutan.

Bab 6 • Menengah

Fungsi Logika dan Perhitungan Bersyarat

6.1 IF

IF memilih hasil berdasarkan syarat. Sintaks: =IF(tes_logika,nilai_jika_benar,nilai_jika_salah).

=IF(C2>=75,"Lulus","Remedial")

6.2 AND, OR, NOT

AND benar jika semua syarat benar; OR benar jika minimal satu syarat benar; NOT membalik nilai logika.

=IF(AND(C2>=75,D2>=75),"Tuntas","Belum Tuntas")

6.3 Fungsi bersyarat

FungsiContohKegunaan
SUMIF=SUMIF(A2:A20,"Makanan",C2:C20)Menjumlah satu kriteria
SUMIFS=SUMIFS(D2:D100,A2:A100,"Lunas",B2:B100,"Oktober")Menjumlah beberapa kriteria
COUNTIF=COUNTIF(C2:C30,">=75")Menghitung data sesuai kriteria
COUNTIFS=COUNTIFS(A2:A100,"Kelas 7",C2:C100,">=75")Menghitung beberapa kriteria
AVERAGEIF=AVERAGEIF(A2:A20,"Kelas 7",C2:C20)Rata-rata sesuai kriteria
Pemisah argumen rumus bisa berupa koma (,) atau titik koma (;) sesuai pengaturan regional. Jika rumus ditolak, coba ganti pemisahnya. Teks kriteria perlu tanda kutip lurus.

Bab 7 • Menengah

Fungsi Teks, Tanggal, dan Pencarian Data

7.1 Fungsi teks

FungsiContohKegunaan
LEFT=LEFT(A2,3)Ambil 3 karakter dari kiri
RIGHT=RIGHT(A2,4)Ambil 4 karakter dari kanan
MID=MID(A2,2,5)Ambil karakter dari posisi tertentu
LEN=LEN(A2)Hitung panjang teks
TRIM=TRIM(A2)Hapus spasi berlebih
UPPER / LOWER=UPPER(A2)Ubah huruf besar/kecil
PROPER=PROPER(A2)Kapital pada awal kata
CONCAT=CONCAT(A2," ",B2)Gabungkan teks

7.2 Tanggal dan waktu

  • =TODAY(): tanggal hari ini.
  • =NOW(): tanggal dan waktu saat ini.
  • =DAY(A2), =MONTH(A2), =YEAR(A2): mengambil bagian tanggal.
  • =DATE(2026,10,21): membuat tanggal.
  • =NETWORKDAYS(A2,B2): menghitung hari kerja antara dua tanggal, tanpa daftar hari libur tambahan.

7.3 IFERROR

=IFERROR(A2/B2,0) menampilkan 0 jika perhitungan menghasilkan kesalahan. Gunakan hati-hati agar kesalahan data penting tidak tersembunyi.

7.4 VLOOKUP dan XLOOKUP

VLOOKUP mencari nilai di kolom pertama rentang tabel dan mengambil data dari kolom di sebelah kanan.

=VLOOKUP(E2,$A$2:$C$100,3,FALSE)

Pada versi yang mendukung XLOOKUP, rumus ini lebih fleksibel:

=XLOOKUP(E2,A2:A100,C2:C100,"Tidak ditemukan")

Alternatif lain: =INDEX(C2:C100,MATCH(E2,A2:A100,0)). XLOOKUP tidak tersedia pada semua versi Excel lama.

Bab 8 • Menengah

Sort, Filter, dan Validasi Data

8.1 Sort dan Filter

Sort mengurutkan data naik/turun. Filter menampilkan baris yang memenuhi kriteria. Pilih tabel, lalu gunakan Data → Sort atau Filter. Pastikan seluruh tabel ikut tersortir agar nama dan nilainya tidak tertukar.

8.2 Remove Duplicates

Data → Remove Duplicates menghapus baris duplikat berdasarkan kolom yang dipilih. Buat salinan cadangan sebelum menjalankannya karena data akan berubah.

8.3 Data Validation dan dropdown

  1. Pilih sel yang akan dibatasi.
  2. Data → Data Validation.
  3. Pilih Allow: List.
  4. Isi Source dengan daftar status atau rentang sel yang berisi pilihan.
  5. Uji dropdown pada sel.

8.4 FILTER dan UNIQUE

Pada versi yang mendukung dynamic arrays, =FILTER(A2:C100,C2:C100>=75,"Tidak ada data") menampilkan baris yang nilainya minimal 75. =UNIQUE(A2:A100) membuat daftar nilai unik.

Contoh daftar status pembayaran: Lunas, Belum Lunas, Cicilan. Dropdown membantu menjaga konsistensi penulisan data.

Bab 10 • Lanjutan

PivotTable untuk Merangkum Data

PivotTable merangkum data panjang tanpa perlu menulis banyak rumus. Contoh: total penjualan per kategori, jumlah siswa per kelas, atau pengeluaran per bulan.

Membuat PivotTable

  1. Pastikan data memiliki satu baris header, tanpa baris kosong di tengah dan tanpa sel gabungan.
  2. Klik salah satu sel pada data.
  3. Insert → PivotTable, tentukan lokasi, lalu klik OK.
  4. Tarik field ke Rows, Columns, Values, atau Filters.
  5. Periksa jenis perhitungan di Value Field Settings; pilih Sum jika ingin menjumlah.
  6. Setelah sumber berubah, klik kanan PivotTable → Refresh.

Bab 11 • Lanjutan

Mencetak dan Mengekspor ke PDF

11.1 Pengaturan halaman

  1. Page Layout → Orientation: Portrait atau Landscape.
  2. Pilih ukuran kertas dan Margins.
  3. Tentukan Print Area jika hanya sebagian data yang dicetak.
  4. Gunakan View → Page Break Preview untuk melihat batas halaman.
  5. Periksa File → Print sebelum mencetak.

11.2 Judul berulang dan header/footer

Page Layout → Print Titles dapat mengulang baris header di setiap halaman. Header/footer dapat memuat judul dokumen, tanggal, atau nomor halaman.

11.3 Ekspor PDF

Pilih File → Save As atau Export, lalu PDF. Pastikan orientasi, ukuran kertas, area cetak, dan jumlah halaman sudah benar. Opsi Fit All Columns on One Page membantu menyesuaikan lebar, tetapi periksa agar teks tidak terlalu kecil.

Jika hanya ingin mencetak e-book web ini, gunakan tombol “Cetak / Simpan PDF” pada menu. Pada jendela cetak browser pilih “Save as PDF”.

Bab 12 • Lanjutan

Proteksi dan Kebersihan Data

12.1 Proteksi

Review → Protect Sheet dapat membatasi perubahan sel. Protect Workbook dapat melindungi struktur workbook. Simpan kata sandi dengan aman. Proteksi worksheet bukan pengganti enkripsi yang kuat untuk data rahasia.

12.2 Backup dan versi file

Gunakan nama file yang jelas, misalnya Laporan_Stok_2026-10-21.xlsx. Simpan salinan cadangan di lokasi aman dan jangan menimpa satu-satunya salinan data penting.

12.3 Membersihkan data

  • Pastikan setiap kolom memiliki header unik.
  • Periksa tanggal dan angka agar tersimpan sebagai jenis data yang tepat.
  • Hilangkan spasi berlebih dengan TRIM.
  • Gunakan Find & Replace atau Text to Columns sesuai kebutuhan.
  • Hapus duplikat hanya setelah membuat salinan cadangan.

12.4 Privasi

Jangan membagikan data pribadi siswa, nomor identitas, alamat, atau informasi keuangan kepada pihak yang tidak berwenang. Gunakan data contoh untuk latihan.

Bab 13 • Lanjutan

What-If Analysis, Power Query, dan Macro

13.1 What-If Analysis

Fitur ini membantu menguji perubahan asumsi. Goal Seek mencari nilai input yang diperlukan agar rumus mencapai hasil tertentu; Scenario Manager menyimpan skenario; Data Table membandingkan beberapa nilai input.

13.2 Goal Seek

  1. Buat sel hasil yang dihitung dengan rumus.
  2. Data → What-If Analysis → Goal Seek.
  3. Set cell: sel hasil; To value: target; By changing cell: sel input yang boleh berubah.
  4. Klik OK dan periksa apakah hasil masuk akal.

13.3 Power Query

Power Query digunakan untuk mengimpor, membersihkan, menggabungkan, dan memperbarui data dari sumber yang didukung. Pada Excel desktop, cari Data → Get Data atau From Table/Range, lakukan transformasi, lalu Close & Load. Menu dan konektor berbeda menurut versi.

13.4 Macro dan VBA

Macro merekam atau menjalankan rangkaian tindakan. VBA dapat mengotomatisasi pekerjaan lebih lanjut pada Excel desktop yang mendukungnya. File macro biasanya memakai format .xlsm. Jangan mengaktifkan macro dari sumber yang tidak dipercaya.

Fitur lanjutan tidak tersedia secara identik pada semua versi Excel, khususnya Excel web dan versi lama. Periksa versi aplikasi sebelum mengikuti langkah.
